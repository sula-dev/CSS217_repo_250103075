# Applied Engineering Lab: Multi-Pattern Architectural Challenges

This project contains complete implementations for all 5 tasks of the Practical Design Patterns Lab:

- **Task 1:** Secure Data Exporter Pipeline (Strategy + Decorator)
- **Task 2:** Legacy Stock Ticker with Rate Limiting & Caching (Adapter + Proxy)
- **Task 3:** Cross-Platform Alert & Incident Engine (Bridge + Strategy)
- **Task 4:** E-Commerce Surcharge & Customs Pipeline (Adapter + Decorator)
- **Task 5:** Remote Cloud Asset Downloader & Security Gate (Bridge + Proxy)

## How to Run

Compile and run each runner class independently:
- `task1.Task1Runner`
- `task2.Task2Runner`
- `task3.Task3Runner`
- `task4.Task4Runner`
- `task5.Task5Runner`
